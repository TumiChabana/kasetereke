# Data Classification

| Class | Meaning | Examples |
|-------|---------|----------|
| Public | Anyone can see it | Listings, district information |
| Private | Personal data about a user | Name, email address, phone number |
| Confidential | Business records, only for authorised roles | Bookings, payment references, transaction hashes |
| Restricted | Highest protection, never shown or shared | Password hashes, tokens, keys, administrator configuration, wallet keys |
