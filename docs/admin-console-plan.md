# Admin Console Plan

The admin console is a separate site in the folder apps/admin. It is plain HTML, CSS, and JavaScript, and it is hosted on its own domain.

## Screens

| Screen | Who can open it | What it shows |
|--------|-----------------|---------------|
| Sign in | Everyone | A form for signing in. |
| Dashboard | Administrator | Totals for bookings, reviews, and listings. |
| Listings | Administrator | A list of all places. |
| Bookings | Administrator | A list of all bookings, with the verify result of each hash. |
| Reviews | Administrator | A list of all reviews, with a delete button. |
| Users | Administrator | A list of profiles and their roles. |
| Security Configuration | Security Officer | The settings described in security-configuration.md. |

Note 1: The screens are a proposal and need the approval of the group.

Note 2: The dashboards for the artificial intelligence part belong to the teammate who owns data and artificial intelligence, so they are not listed here.
