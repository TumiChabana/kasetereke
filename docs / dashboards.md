# Dashboards

This document follows the screens listed in admin-console-plan.md.

## Operator dashboard

| Widget | What it shows |
|--------|---------------|
| My listings | The listings that belong to the signed-in operator |
| Bookings for my listings | The bookings made for those listings, with their status |

An operator never sees the listings or bookings of another operator.

## Overview for the Admin

| Widget | What it shows |
|--------|---------------|
| Bookings total | The total number of bookings |
| Reviews total | The total number of reviews |
| Listings total | The total number of listings |

## Security Officer

The Security Officer does not have a dashboard. This role opens the Security settings screen, which shows the settings described in security-configuration.md.

## Dashboards for the artificial intelligence part

The Streamlit dashboards for Part D belong to the teammate who owns data and artificial intelligence. They are not described in this file.

Note: The dashboards are a proposal and need the approval of the group.
